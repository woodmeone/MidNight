# T2 · 深联想质量门槛 + 条数硬上限

**Status**: ✅ DONE 2026-09-08（与 T1 一并实现：`TAG_CANDIDATE_CAP` 硬上界）
**Blocked by**: T1
**Spec**: P1（堵评论区痛点②的尾巴）

## 做什么
深联想（`recall_associative` 里"拉语义相通但字不相干的 chunk"，如 压力→紧张→雅思）加两道闸：
1. **激活强度门槛**：只有激活强度 ≥ 独立下限的 tag 才允许拉深联想 chunk（现在 hit 到强于 0 就进）。
2. **条数硬上限**：extra 深联想条目封顶（如 ≤ 3），防止几十条弱联想糊进上下文。

## 为什么（应用例子）
- **例**：赖老师问"这周张娜该练啥"，模型状态好时若能分心，青岚可能把"蒋之泰嘴碎""熊可婷想学MJ"这些**八竿子打不着但沾了个关系**的旧账也倒进去 → 回答开始编。
  - **现状**：只要某个 tag 激活强度 > 0 就可能被拉进来，门槛约等于没有。
  - **改后**：强度不够的 tag **不触发深联想**；就算触发，extra 最多 3 条，噪音进不了上下文。

## 验收
- 已有测试全绿。
- 新增用例：弱激活 tag 不产生深联想条目；深联想条目数 ≤ 上限；上下文不被无关旧账污染。
