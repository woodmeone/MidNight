## 问题

智能体每次开工是空白的。它手里其实攒着三样自己的东西——人设、资产、记忆——但会话第一条它一个都看不见。

实证（开编 kaibian，2026-11-14 日记）：

> 失：我还是先按文档思路做了一遍，是用户提醒才想到存可执行资产。
> 下次项目收尾时应当默认问一句：这次的哪些动作可以脚本化？

它**已经建出** `kb/ refs/ tools/ snippets/ templates/ checklists/` + `ASSETS.md`，
却在干活时看不见它们。那一声「用户提醒」，就是本方案要消掉的东西。

## 第一性原理：三样的存在形式不同，看见方式就不同

| | 谁生出来的 | 会变吗 | 怎么看见 | 为什么 |
|---|---|---|---|---|
| **人设** | 自己 + 演化 | 慢（月/年） | 读 `self.md` | 一个文件，读完就是全部 |
| **资产** | 自己建、会增删改 | 快（周/月） | **扫目录** | 写死人设就会过期，只有目录是真相 |
| **能力** | 外部给（技能库） | 随版本 | 一句指路 + 记忆积累 | 存在性写一句永久有效；经验自然沉淀 |
| **同伴** | 外部给（目录） | 少 | 一句指路 + 记忆积累 | 遗漏代价低，联想能带出「该问谁」 |
| **记忆** | 自动写 | 只增 | **联想召回** | 591 篇列不出来，只能按话题捞 |

三条推论：

1. **自己长出来的要扫，外面给的只要一句指路。** 资产必须扫；能力/同伴不必。
2. **能力分两层**：存在（扫得到、但不必每会话给）+ 经验（哪个顺手，已经在记忆里）。
   后者已经跑通了——本轮对话每次 `prep.py` 都会召回「recall.py 没有 `--tag-weight`」这条教训。
3. **联想只管库外往上下文捞。** 已经注入的不再捞，所以资产清单和联想不在同一条赛道上。

## 被否决的方案（别重蹈）

| 方案 | 否决理由 |
|---|---|
| 资产正文进 `chunks` 表 | 污染 `importance` / `--decay` / 只增不减语义；代码和图片进了库也不能执行/显示 |
| 资产走向量检索 | 是「自己建、自己知道有什么」的活集合，扫描比语义准；向量算半天还给近似值 |
| 资产做 `find / list / show` 命令 | 多一次往返、多一百字。skill 没有这一步，资产也不该有 |
| 能力清单进开机清单 | 每会话白付 token 买一份自己用不上的目录；经验层记忆已经覆盖 |
| 同伴名单进开机清单 | 想不起 mira 还能自己干，想不起 image-gen 是**真不知道怎么做**——两者不对称 |
| 系统预设 `kind: framework/doc/code` 枚举 | 开编用的是 `tools/snippets/templates/checklists`——**动词判据（拿出来做什么）比名词判据（它是什么）好用** |
| 给 skill 打分 | 伪精确，要维护要校准，还把「为什么」丢了 |

## 目标形态

### 开机清单（会话第一条，只注入一次）

```
[开机] 我是开编｜第一性原理、复用优先、克制｜边界:不收噪音进 kb

资产  tools 2 · snippets 1 · templates 5 · checklists 1 · kb 12 · refs 14
      → <工作区>/ASSETS.md
```

约 60 字，硬预算 120 字。

### 资产三级加载

```
① 一行类目（开机清单）
      ↓ 想用某一类
② read ASSETS.md（总索引，建资产的人自己写）
      ↓ 挑中一件
③ read tools/upstream_preflight.py
```

三次 `read`，零次查询。

### 能力与同伴

不在清单里。`self.md` 写两句：

```markdown
## 我的路径
遇到不会的活，先查技能库——那里有现成的做法，别自己从零造。
有事可以问同伴，别一个人硬扛。
```

一次成本，永久有效。经验靠日记 `tags: [skill经验, ...]` 积累，联想自然带出。

## 术语（→ CONTEXT.md）

- **开机清单（boot manifest）**：会话第一条注入的固定块，只有人设摘要 + 资产索引，硬预算 120 字。
- **资产（asset）**：智能体自己建的、会增删改的长期可复用物。存在形式是工作区目录 + `ASSETS.md` 总索引，**不进数据库、不做向量**。
- **三级加载**：一行类目 → `ASSETS.md` → 具体文件。加载靠 `read`，不靠查询命令。
- **能力经验**：某个 skill/工具「什么场合好用、什么场合不好用」的判断。存在形式是日记，靠联想召回，不打分。

## 不变量（硬约束）

1. **不破坏现有记忆库**：不 `DELETE`、不 `DROP`、不改 `chunks.content`。唯一允许的写操作是 Issue 03 里对 `files.file_path` 的 `UPDATE`，且必须 `--dry-run` 默认、执行前备份。
2. **只读优先**：三张 Issue 里只有 Issue 03 碰数据。
3. **默认关闭新行为**：`boot.py` 是新增独立入口，不进任何现有 CLI 的默认路径。现有 `prep.py` / `recall.py` 行为逐位不变。
4. **零外部服务**：Python + SQLite + 文件系统，不加依赖。
