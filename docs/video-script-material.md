# Midnight Skills — 视频脚本素材（项目背景 / 痛点 / 优化决策）

> 用途：撰写技术视频脚本的一手素材。结构按"讲故事的起承转合"组织，
> 每个论点附带一个"可口头讲的小例子"。
> 日期：2026-09  状态：素材稿（非规范，供叙事扩展）

---

## 一、一句话定位（视频开场可用）
给"AI 装上一副长期记忆"这件事，我们走过三套思路、推翻过自己的设计两遍，
最终想清楚：**我们要的不是让 AI 更会"伺候一个人"，而是让它成为"有独立自我、会认识很多人、
靠联想而非档案活下来的个体"。**

---

## 二、背景：一个被所有人忽略的困局

传统 AI（对话模型）有个致命缺陷：**无状态**。你问一句，它醒来；答完就睡；下个会话把你忘光。

- 第一层痛：**它不记得你** → 每次重介绍自己。
- 第二层痛（更隐蔽）：**它不知道它该想起什么**。连"该不该查记忆"都由它自觉。
  例子：你三个月前提过"要考雅思"。三个月后你只说"最近压力好大"。
  传统系统不会把"压力"连到"雅思"——因为你不提"雅思"，它也想不起要查"雅思"。
  这就是经典的鸡生蛋：**你提它它才找，它不记得就不知道怎么找。**

几乎所有"AI 记忆"项目，都在绕着这个死结打转。而我们在这条路上发现两条截然不同的解法。

## 三、三个项目的思想碰撞（本文核心张力）

### 参考 A：VCP — "别让 AI 自己去想，服务端替你回忆"
- 代表作理念：一套"持久城市"白皮书式全栈系统。每次请求进模型前，**服务端强制拦截**，
  先把记忆/工具/时间/跨端全量注入上下文，再发答案。本质：AI 不决定"要不要回忆"，服务端替你决定。
- 可取之处：联想算法 TagMemo（V9.1）很厉害。你会发现它不只是"关键词找相似"，
  而是把标签建成带方向的图：有序双向边、对数压缩防高频词垄断、入流枢纽校正、能量不无限扩散、
  Core/Ghost 预感应…… 它让 AII 能沿"概念间的关系路径"延续推理，而不是在字面里打转。
- 问题（被我们质疑）：① 无脑每轮全量灌 → 上下文塞爆、闲聊也触发一堆噪音，违背"人不是每次开口都翻遍终身记忆"。
  ② 项目"学术派的傲慢"：功能很重，到处有扩展跟框架，对一个要"轻量可用 + 可拼装"的目标太挡路。
  ③ 结构上 AI 更像"装置/仆从"，不是"独立个体"。

### 参考 B：Le tta（MemGPT 改名后）— "把记忆做成一棵文件树"
- 代表作理念：Agent 不该只有一次性上下文，要让模型像操作系统管内存一样**分层管理**：
  常驻核心 block + 外部海量记忆 + 按需换页。所有记忆是一个 **git 追踪的目录树(MemFS)**，
  且能**编译进 system prompt**——"core memory 是定义你的程序"，散落对话走 /search 外查。
- 可取之处：① 给"agent 可自我改记忆/技能"的思想，② 渐进式露出(平时只放核心，要用再加载)，
  ③ 记忆有版本/可跨模型。这些正好治"上下文过曝"。
- 问题（我们讨论后放弃照搬的）：它默认 **persona / human 等固定 md 档** —— 实为"AI 对某一位 owner
  的服务配置"。一旦有多个对话对象、长期跨会话，固定块会变得僵硬、且把 AI"焊"成一个主题的仆从。
  这跟我们想要的"一个持续的、有多人认识的独立自我"相反。

### 我们自己的 Midnight — "skill 式轻量联想"
- 现状：Reasix 技能，本地 SQLite 一套（recall/core/pulse/compass），
  已有：diary 入库(切块向量化)、KNN+tag 共现+BFS 脉冲联想、time 加权、importance、多 agent 物理隔离。
- 问题：整体偏"skill 式 AI 自觉触发 + 平铺日记"。① AI"自己想不想想起"决定结果（自觉不可靠、漏）。
  ② 记忆平铺无 self/对象结构的区分，无法表达"关于你(阿散)"和"我是一个Mira" 两条线。
  ③ 联想太浅（共现+BFS），不如 VCP 那些防噪声的方向算法。
  ④ 想解决"规则写死就硬 / 常驻塞上下文"时，早期一度想抄 letta 的 persona md 全档，后被推翻。

## 四、被推翻的两次设计（叙事转折点）

1. **一度想"做回 VCP 服务器"**：看到 VCP 服务端拦截效果好，几乎要 push 回去做微服务版记忆服务器，
   让 AI 每次都强制 recall。辩论后放弃：① 服务器强制全量灌 = 噪音与上下文塞爆，
   变成"强迫症 AI 每次翻遍一生"；② 单机自用 return 到无脑架构；C 若仅自己用不该上服务器重资产。
   结论：效果不是堆服务器，是记忆**建模 + 联想质量**。

2. **一度照搬 letta persona/human 固定档**：写到用户故事时把"AI 开场认人"写成"给 persona/human 建 md",
   用户点评到根：**那会让你变成"只服务一个主人、绑死一个场景、换会话就散"的仆从；
   也会把规则焊死、太硬。** 由此定稿为：**Self 是一个"活的定位"(也随学习演化)，而人/对象 = 标签+日记 走联想。**

## 五、定稿方案（视频可用作卖点 / 演示前说清楚）

**目标一句话**：让 Midnight 把一个 Agent 升级成有独立自我、对遇到的人各建"对象日记"、
靠跨概念联想（马拉松→阿散）延续记忆、还能逐步自我演进定位的个体。

三层记忆：
- **Self 层**：身份/能力/价值/连续性。含「定海锚」(核心身份基线, 只读或高门槛) + 「可动层」(偏好/风格/能力边界, 可被经历改写)。→ 自进化但不丢失"我是谁"。
- **Object 层**：每个遇到的 person/组织 = 一本 diary(anchor tags)，默认使用者；对象↔self↔话题 多对多。
- **Event/泛化层**：从经历提炼稳定模式(Generalize)，通过高频强化/久不用衰减在权重里演化，**不写死 rules.md**。

联想深(抄 VCP 的轻量版)：方向边/对数压缩/枢纽校正/预算守恒/Core-Ghost 预感应——
让 马拉松→阿散 这种跨概念多跳联想稳定、不被高频词骗。

上下文编排(可选)：session_start 把 self 摘要+本次对象 anchor 编译进首轮(对标 letta 但只小量)，避免上下文爆。

**例子（可演示）**：给 agent"Mira"装上 Midnight。
- 她给自己定位：助理 Mira、会用 Python & 懂 DSH 工程。
- 认识你：你叫阿散。她为"阿散"锚定 tags{马拉松、Python、深夜在线、DSh 工程…}。
- 换会话后你问"我提过跑马拉松吗" → 她不翻"阿散档案"，她脑中 马拉松↔阿散 的边被激活
  → 记起"你说过、赛前紧张、还和雅思撞期一次"。这是"经历网络去查"，不是档案检索。
- 甚至有次她上网调研"马拉松安全训练"，之后给你讲时自然带上("你不是说想跑首马吗")。

## 六、这条路上的"认知升级"式洞察（适合做成转场/收尾）

1. **记忆产品不该是"提高检索的 RAG"，而是"记忆建模 + 联想质量"**。
2. **两种参考都过半**：VCP 只做"服务端替你强制回忆"(可靠却塞爆)，
   letta 把记忆做成"一堆档"(适合一主一户)。而独立个体 + 对象网络 + 联想，才是"人样"的记忆。
3. **固定规则会僵硬**：规则做活(权重演化)比做成配置文件更适合多变会话的 AI。
4. **"AI 该什么时候回想"是伪命题里最伪的部分**：与其赌它自觉触发(VCP 就赌服务端全)，
   不如给它一副"知道去哪查"的联想网络——它总有路，不是每次都全翻，也不是完全靠自觉。
5. **自己在开发中的自我批评救了对架构的偏见**：两度推翻自己的设计(服务器、persona)，
   才留下"self+object+联想+演化的轻skill"。这就是值得讲的成长过程。
