# ADR-0003: 联想主干 + 约束，取代"三条并列通道"的拆法

- 状态：已接受（2026-10-21）
- 关联：Issue #7；修订 ADR-0002 的"三条通道"表述；`skills/recall/scripts/recall.py`

## 背景

ADR-0002 把检索定成"三条通道"：联想（默认）、确定性（时间轴/字面）、md 原文（例外）。这个拆法解决了"AI 答不了日期问题只能去翻文件"，但**拆过头了**——它把同一件事的两个维度（相关性 vs 时间范围）误当成两种不同的东西。

代价在真实使用里立刻出现。用户问「十月以后关于备课的进展」，实际要做两次调用：

```bash
recall.py --timeline 10 --since 2026-10-01   # 拿时间线：按日期，不带语义
prep.py --query "备课 教案"                   # 拿语义：候选池**不受时间窗约束**
```

结果要人在脑子里对齐，而且语义那条腿是越界的——它可能把八月的备课记忆捞回来。更糟的是 CLI 直接拒绝这个组合（"`--since/--until` 只能与 `--timeline` 或 `--literal` 一起用"）。

## 决定

把检索定成**一条主干 + 两个可选约束**：

```
候选池（全库 / 倒排预筛）
  → 【约束 A】时间窗：substr(COALESCE(diary_date, created_at),1,10) BETWEEN since AND until
  → 【约束 B】字面：content LIKE %字面%
  → 主干：向量 KNN + 标签脉冲 + 时间加权 + tag-first 扩增 + MMR
  → 去重 → 预算 → 注入
```

1. **约束作用在候选池阶段**（过滤"在哪些记忆里找"），主干作用在其内（排序"哪条最像"）。
2. **时间窗必须压在两处**：向量候选池的 SQL，**以及** `expand_tag_candidates`。只压一处，携带激活标签的窗外记忆会从后门溜回来，窗口形同虚设。
3. **缓存键必须含窗口**：同一 query 带窗与不带窗是两次不同的检索，共用缓存即脏读。
4. **`--timeline` / `--literal` 保留**，但重新定位为"约束的退化形态"——只有约束、不做语义排序。回答"最新一条是哪天 / 有没有提过某词"仍然需要它们（那种问题不需要排序）。
5. **md 原文例外的铁律不变**（ADR-0002 仍然有效）。

## 理由

- **约束 ≠ 排序**。排序要"排完再筛"就错了：top-k 先被窗外记忆占满，筛完只剩零星几条甚至空。约束必须发生在打分之前。
- **一次调用好过两次再对齐**。两次调用的对齐工作落在人（或 AI 的下一次推理）身上，错了没人发现；一次调用在库内取交集，边界由 SQL 保证。
- **概念少一个**。三条并列通道要用户理解"哪条该用哪条"；一条主干 + 两个约束只需要理解"我要不要限定范围"。SKILL.md 的篇幅和记忆负担都降了。
- **退化形态有独立价值**。"最新一条是哪天"本质是求 max，不需要相关性；硬套主干反而要用 `--timeline` 模拟。

## 后果

- 正面：「十月以后关于备课的」一次调用；窗口对向量层与标签扩增同时生效；缓存不再脏读。
- 正面：`prep.py`（默认入口）也支持窗口，与 `recall.py` 同口径校验日期。
- 代价：`recall_with_identity` / `auto_recall` / `expand_tag_candidates` / `recall` 四个函数的签名各多两个参数（默认 None，关闭时逐位等于旧行为）。
- 代价：留痕的 `extra` 多两个字段（`since`/`until`），审计时要看窗口才读得懂"为什么只命中 2 条"。
- 约束：**不要再给检索加"第四条通道"**。新需求先问"这是约束还是排序"——是约束就压候选池，是排序就进主干。
- 注意：时间窗只认绝对日期（`YYYY-MM-DD`）。"上周""国庆后"由上层 AI 换算成绝对日期再传，脚本不猜——猜错时间窗比不设窗更糟。

## 替代方案

- **保持三条通道，只让 CLI 允许 `--query --since`**：能跑通，但概念仍是三通道，文档要继续教"哪条对哪条"，且 `--since` 挂在 `--query` 上会被误读成另一种通道。否决。
- **在 `recall_associative` 里排完再筛**：实现最省事，但 top-k 已被窗外记忆占满，会少返回甚至空。否决。
- **让 `--timeline` 也做语义排序**：那就等于主干 + 窗口，多一个重复入口。否决。
